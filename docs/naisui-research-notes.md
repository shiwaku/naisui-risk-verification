# 内水氾濫リスク推定の検証 — 調査メモ

作成日: 2026-09-23
目的: 内水ハザードマップが未整備の地域について、公開されている地形データ（標高・地形分類）から内水氾濫が起こりやすい場所を推定できるかを、浸水実績と既存の内水浸水想定区域を使って検証する。

---

## 1. 背景と問い

- 重ねるハザードマップでは、内水ハザードマップの整備が洪水（外水）に比べて遅れている。
- 問い: **標高タイル／DEMなどの地形データだけで、内水氾濫が起こりそうな地域をどこまで推定できるか？**
- 結論（事前調査時点）: 「起こりやすさの目安（スクリーニング）」としては可能。ただし下水道の排水能力などは地形データからは分からないため、正式な内水浸水想定の代わりにはならない。

---

## 2. 内水氾濫のメカニズム

内水氾濫とは、堤防の内側（堤内地）に降った雨が、川や海へ排水しきれずに溜まる現象。

雨水の流れ: 降雨 → 地表流 → 側溝・雨水桝 → 下水管 → ポンプ場・樋門 → 河川・海
（このどこか1か所でも処理能力を超えると浸水が起きる）

| # | メカニズム | 典型的な状況 | 起こりやすい場所 |
|---|---|---|---|
| 1 | 下水道の能力超過 | 短時間の強い雨が設計能力（時間雨量50mm前後が多い）を超える | 都市部全般 |
| 2 | 排水先の水位上昇（はけ口の閉塞） | 河川の水位上昇で樋門を閉鎖し、ポンプだけでは排水しきれない | 河川沿いの低平地 |
| 3 | 地形による集水（窪地への湛水） | 周囲から流れてきた水が低い場所に集まり、抜けなくなる | 台地上の凹地、谷底低地、アンダーパス |
| 4 | 地盤が排水先より低い | ポンプの能力超過や停電 | ゼロメートル地帯、干拓地 |
| 5 | 局所的な要因 | 雨水桝の詰まり、地下空間への流れ込み | 個別の地点 |

浸水の起こりやすさを左右する要素: 降雨の強さと継続時間、不浸透面の割合、集水面積、地形、排水施設の能力、河川の水位。

### 本検証で捉えられる範囲

| メカニズム | 捉えられるデータ | 捉えやすさ |
|---|---|---|
| 3 地形による集水 | DEMの窪地、地形分類の凹地・浅い谷 | ◎ |
| 4 地盤が排水先より低い | 地形分類（干拓地・旧水部）、標高 | ○ |
| 2 排水先の水位上昇 | 地形分類（後背低地）、河川との比高（HAND） | △ |
| 1 下水道の能力超過 | 地形データからは分からない | × |
| 5 局所的な要因 | 捉えられない | × |

**解釈の方針**: 浸水実績はすべてのメカニズムが混ざった結果。地形による推定で説明できなかった浸水は「地形以外の要因（下水道の能力など）によるもの」と解釈でき、一致しなかった部分も分析結果として意味を持つ。

## 3. 使用するデータ

### 3.1 DEM（標高）

- 推奨: **基盤地図情報 数値標高モデル（5mメッシュ、航空レーザ測量）**を XML から直接 GeoTIFF に変換する。
  - 入手先: 基盤地図情報ダウンロードサービス https://fgd.gsi.go.jp/download/
- 地理院の標高タイルはWebメルカトルのため、再投影すると標高値が補間される。窪地の深さは数十cm単位の差を扱うので、分析用には使わない（表示用なら可）。
- 注意: 誤差は数十cm程度。測量後の造成が反映されていない場合がある。橋や高架が「堤防」のように残り、見かけの窪地ができることがある（デンマークのBluespotでも橋の除去処理を行っている）。

### 3.2 地形分類（国土地理院 ベクトルタイル提供実験）

- 解説: https://www.gsi.go.jp/bousaichiri/lfc_index.html
- 配信仕様: https://github.com/gsi-cyberjapan/experimental_landformclassification
- 形式: **GeoJSONタイル**（MVTではない）
  - 自然地形: `https://cyberjapandata.gsi.go.jp/xyz/experimental_landformclassification1/{z}/{x}/{y}.geojson`
  - 人工地形: `https://cyberjapandata.gsi.go.jp/xyz/experimental_landformclassification2/{z}/{x}/{y}.geojson`
  - スタイル定義（コードと名称の対応を確認できる）: 各ディレクトリの `style.js`
- **ズームレベルの注意**: 人工地形はズームレベル14〜16のみが実データで、4〜13はおおよその範囲図。自然地形の詳細版もズームレベル14〜16。→ **ズームレベル14以上で取得する**（ズームレベル14と16の形状差は要確認）。
- 元データ: 土地条件図、脆弱地形調査、治水地形分類図（更新版）、沿岸海域土地条件図を統合したもの。
- 注意: 表示されるリスクは分類ごとの一般的な傾向。境界線は作成当時の地形図に基づく。詳細版は全国をカバーしていない。位置づけは「提供実験」で、基本測量成果ではない。利用条件は国土地理院コンテンツ利用規約に従う。

内水に関係が深い分類:

| 区分 | 分類 | 内水との関係 |
|---|---|---|
| 自然地形 | 凹地・浅い谷 | 大雨で雨水が一時的に集まりやすい。台地上の内水を拾える（最重要） |
| 自然地形 | 後背低地・湿地 | 周囲よりわずかに低く、水はけが悪い |
| 自然地形 | 旧河道 | 周囲よりわずかに低く、水はけが悪い |
| 自然地形 | 落堀 | 堤防沿いの凹地状の土地 |
| 自然地形 | 旧水部 | かつての海・池。現在の標高からは見えない過去の低地 |
| 人工地形 | 干拓地 | 一般に海面・湖面より低く、氾濫水が溜まりやすい |
| 人工地形 | 盛土地・埋立地 | 盛土で窪地が消えていても、元の地形はリスクを持つ可能性 |

DEMとの違い: DEMの窪地は「現在の地表の形」、地形分類は「盛土などで変わる前の地形」も反映する。両者は補完し合う。

### 3.3 浸水実績（水害履歴）

- 変換ツール: https://github.com/shiwaku/ksj-suigai-rireki-converter
- 内容: 1896〜2019年の浸水実績ポリゴン（60 Shapefileを統合、14,585件）
- 変換済みファイル: `output/sinsui_all.gpkg`（レイヤ名 `sinsui`、EPSG:6668）、ほかに GeoJSON / FlatGeobuf / CSV / PMTiles
- 付与されている属性: `date_iso`, `event_year`, `event_month`, `era_label`, `typhoon_file`（ファイル名から判断した台風由来かどうかの目安）, `src_file`
- ビューワ: https://shiwaku.github.io/ksj-suigai-rireki-converter/app/
  - Mapterhornの地形と重ねて表示でき、段彩の標高レンジを0〜5mに狭めると微小な窪地が見える。
- **注意**:
  - 内水と外水が区別されていない（伊勢湾台風の高潮なども含まれる）。
  - 大規模な災害が中心で、局地的な豪雨による小規模な内水浸水は記録されていない可能性が高い。
  - `disastName` が NULL のレコードが37件ある。

### 3.4 雨水出水（内水）浸水想定区域 — 検証用の正解データ

- 国土数値情報 A51: https://nlftp.mlit.go.jp/ksj//gml/datalist/KsjTmplt-A51-2024.html
- 最新は2025年度版。JPGIS2.1（GML）およびShapefileで提供。
- **内水ハザードマップが整備済みの地域では、これを正解データとして推定手法の精度を測る。**
- 自治体が独自に公開している例もある（広島市はShapefile、平面直角座標系III系で公開）。

## 4. データ形式と座標系

| データ | 元の形式 | 揃える形式 |
|---|---|---|
| 浸水実績 | Shapefile（変換済みgpkgあり） | GeoPackage |
| 内水浸水想定区域 | GML / Shapefile | GeoPackage |
| 地形分類 | GeoJSONタイル | GeoPackage（タイルを結合し、分類ごとにdissolve） |
| DEM | 基盤地図情報XML | GeoTIFF |
| 窪地の抽出結果 | ― | GeoTIFF（ラスタ）＋ GeoPackage（ポリゴン化したもの） |
| Web表示用 | ― | PMTiles（分析には使わない） |

- GeoPackageを選ぶ理由: 1ファイルに複数レイヤをまとめられ、空間インデックスがあり、QGIS・GeoPandas・GDALのどれでもそのまま扱える。
- FlatGeobufは読み込みが速いが、1ファイル1レイヤで編集に向かないため、分析の途中で使う形式にはしない。
- 座標系:
  - 保存用: **JGD2011 地理座標（EPSG:6668）**（浸水実績と同じ）
  - 分析用: **JGD2011 平面直角座標系の対象地域の系**（例: 東京はIX系 EPSG:6677）。窪地埋めや面積の計算にはメートル単位が必要。

## 5. 手法

### 5.1 地形指標

1. **窪地の抽出**: DEMに窪地埋め（fill sinks）処理を行い、元のDEMとの差（窪地の深さ）を算出する。深さ・面積・容量でポリゴン化する。
2. **HAND**（最寄り水路からの相対高さ）: 排水先の水位上昇型（メカニズム2）の目安。
3. **TWI**（地形湿潤指数）: 水が集まりやすく抜けにくい場所の目安。
4. **流向・集水域**: 窪地ごとの上流集水面積を求め、窪地の容量と比較する（Bluespotの順位付けと同じ考え方）。

ツール候補:
- **malstroem**（デンマークのBluespot手法のPython実装）: https://github.com/SDFIdk/malstroem
  - 窪地埋め、流向、累積流量、Bluespot、窪地ごとの集水域、流出点、Bluespot間の流路を計算できる。
- WhiteboxTools、SAGA（QGIS経由でも可）

### 5.2 3層の重ね合わせとスコアリング

① DEMから抽出した窪地
② 地形分類の内水関連クラス（凹地・浅い谷、後背低地・湿地、旧河道、落堀、干拓地、旧水部）
③ 浸水実績

①と②が重なる数でスコアを付ける。③を答え合わせに使い、①と②のどちらの一致率が高いかを比較して、地域に合った指標を判断する。

### 5.3 検証の設計

- **正解データ**: 内水浸水想定区域（A51）がある地域 → 精度を定量的に評価する。
- **補助データ**: 浸水実績 → 内水と外水が混在している点に注意して使う（台風由来のイベントを除外する、河川からの距離で分けるなど）。
- **評価指標の候補**: 浸水域のうち推定域に含まれる割合（再現率）、推定域のうち実際に浸水した割合（適合率）、F値、IoU。
- **適用**: 精度が確認できた手法を、内水ハザードマップが未整備の地域に適用する。

## 6. 既存事例

- **国交省 内水浸水想定区域図作成マニュアル（案）**（令和3年7月）
  https://www.mlit.go.jp/river/shishin_guideline/pdf/naisui_manual.pdf
  - 地形情報や浸水実績を活用して内水浸水を想定する手法が、正式に組み込まれている。
- **浸水実績を活用した内水ハザードマップの作成に係るQ&A集**（国交省）
  https://www.mlit.go.jp/common/001054005.pdf
- **防災科研 防災基礎講座「内水氾濫」**
  https://dil.bosai.go.jp/workshop/03kouza_yosoku/04naisui.html
  - 内水が起きやすい地形として、後背低地・旧河道・旧沼沢地、砂州で閉ざされた海岸低地、台地内の谷底低地、台地面上の凹地や浅い谷、ゼロメートル地帯を挙げている。内水は繰り返し起こりやすく、浸水履歴が危険度判定に使えるとしている。
- **秋田大学 卒業研究（武蔵野台地東部）**
  https://www.akita-u.ac.jp/eduhuman/graduate/abstract_pdf/11-016.pdf
  - 5mDEMと1/2,500地形図から地形・地理的特性を抽出し、主成分分析で過去の浸水箇所と似た地域を抽出。
  - 台地上の谷は、治水地形分類図・土地条件図と5mDEMから見える谷のずれが大きかったため、接谷面から元の標高を引いて抽出している。→ 地形分類とDEMを併用する際の注意点。
- **デンマーク道路局 Blue Spot モデル**
  https://pubmed.ncbi.nlm.nih.gov/22049725/
  - 1.6mグリッドのDTMで約7,500km²を解析し、窪地の深さ・面積・容量、流路、集水域、窪地ごとの順位付けを算出している。
- **Bluespotと実際の浸水域の比較**（Water, 2022）
  https://doi.org/10.3390/w14223742
  - UAS（ドローン）の熱画像による浸水域とBluespotを比較。平坦な土地では、わずかな標高の変化（畑の耕起方向など）で浸水の位置が変わることを示している。

**新規性**: 個々の手法は既に存在するが、国内の公開データ（基盤地図情報DEM＋地形分類＋全国の浸水実績＋A51）を組み合わせ、再現できる形で検証したものは、今回の調査範囲では見つからなかった。

## 9. 前提と限界（README に明記する）

- 本手法は内水氾濫の「起こりやすさの目安」であり、正式な内水浸水想定区域の代わりにはならない。
- 下水道の能力、ポンプ場、雨水貯留施設、道路の縁石・建物・塀による流れの変化は考慮していない。
- DEMの誤差（数十cm）と測量時期、地形分類の作成時期によって、現在の地形と合わない場合がある。
- 浸水実績は内水と外水が混在しており、小規模な内水浸水は記録されていない可能性が高い。
- 地形分類データは国土地理院の「提供実験」であり、基本測量成果ではない。出典を明記する。
